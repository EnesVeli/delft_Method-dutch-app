## DA-002 · Scaffold Next.js 16

**Goal:** A clean, strict, empty Next.js app on `v2` that follows the folder structure in `docs/architecture.md`.

**Context:** `docs/architecture.md` (Stack, Folder structure), `CLAUDE.md` (Code standards)

**Scope**
1. Scaffold with `create-next-app` (latest 16.x): TypeScript, Tailwind CSS v4, ESLint, App Router, `src/` directory, import alias `@/*`, npm. If it refuses the non-empty folder, scaffold into a temp folder and move the files in. Don't overwrite `README.md`, `docs/`, `.gitignore`, or the local `CLAUDE.md` / `AGENTS.md` (create-next-app may generate its own: keep ours, and keep the `@AGENTS.md` line at the top of `CLAUDE.md`). Merge any new `.gitignore` entries instead.
2. Set `engines.node` to `>=20` in `package.json` and add `.nvmrc` with `20`.
3. In `tsconfig.json`, keep `strict: true` and add `noUncheckedIndexedAccess`, `noImplicitOverride` and `noFallthroughCasesInSwitch`.
4. Add Prettier with `prettier-plugin-tailwindcss`: `.prettierrc` (single quotes, semicolons, width 100, `endOfLine: "lf"`) and `.prettierignore`. The repo already has `.gitattributes` forcing LF line endings: keep it.
5. ESLint: add `eslint-config-prettier` so it doesn't fight Prettier, and turn on `@typescript-eslint/no-explicit-any: error`.
6. Scripts: `dev`, `build`, `start`, `lint`, `typecheck` (`tsc --noEmit`), `format` (`prettier --write .`), `format:check`.
7. Create the empty folder skeleton from `docs/architecture.md`, each with a `.gitkeep`: `content/`, `src/features/{lessons,review,progress,auth}/`, `src/content/`, `src/components/ui/`, `src/lib/supabase/`, `src/lib/speech/`, `src/styles/`, `tests/e2e/`.
8. Replace the boilerplate home page with one placeholder: an `h1` "Delft Dutch" and a line "v2 in development". Delete the boilerplate SVGs in `public/`.
9. Set `metadata` in the root layout: title `Delft Dutch`, description from `docs/product-vision.md`'s one-liner, and `<html lang="en">`.

**Out of scope**
- Fonts and colours (DA-006)
- Tests (DA-003)
- PWA (DA-071)

**Acceptance criteria**
- [ ] `npm run dev` serves the placeholder at `localhost:3000`
- [ ] `npm run lint`, `npm run typecheck`, `npm run format:check` and `npm run build` all pass
- [ ] No `any` anywhere, no boilerplate left (Vercel/Next logos, template copy)
- [ ] Folder skeleton matches `docs/architecture.md`
- [ ] `README.md` and `docs/` are unchanged

**Notes**
- Next.js 16 has breaking changes compared with your training data. Read `node_modules/next/dist/docs/` before configuring anything (see `AGENTS.md`).
- Pin exact versions in `package.json` (no `^`) so CI and local runs match.
