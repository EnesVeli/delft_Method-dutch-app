## DA-003 · Test setup: Vitest + Playwright

**Goal:** Unit tests and end-to-end tests run with one command each, with one real passing test of each kind.

**Context:** `docs/architecture.md` (Testing), `CLAUDE.md` (Testing)

**Scope**
1. **Vitest** with `@vitejs/plugin-react`, `jsdom`, `@testing-library/react`, `@testing-library/jest-dom` and `@testing-library/user-event`. Config in `vitest.config.ts` with the `@/*` alias and a setup file `vitest.setup.ts`.
2. Unit tests live next to the file they test (`*.test.ts` / `*.test.tsx`). Exclude `tests/e2e/`.
3. Add the first real utility with tests: `src/lib/cn.ts`, which joins class names and ignores falsy values (`cn('a', false && 'b', undefined, 'c') === 'a c'`). DA-007 will use it.
4. **Playwright** (`@playwright/test`), Chromium only to start with. `playwright.config.ts` starts the app with `webServer` (`npm run build && npm run start` in CI, `npm run dev` locally) and has `baseURL` `http://localhost:3000`.
5. First e2e test in `tests/e2e/home.spec.ts`: the home page loads and shows the heading "Delft Dutch".
6. Scripts: `test` (`vitest run`), `test:watch`, `test:e2e` (`playwright test`).
7. Add Playwright output folders (`test-results/`, `playwright-report/`) to `.gitignore`.

**Out of scope**
- CI (DA-004)
- Coverage thresholds (later)

**Acceptance criteria**
- [ ] `npm test` passes, with at least 3 cases for `cn`
- [ ] `npm run test:e2e` passes locally
- [ ] `npm run lint` and `npm run typecheck` still pass, test files included

**Notes**
- Don't add test utilities "for later". Only what these two tests need.
