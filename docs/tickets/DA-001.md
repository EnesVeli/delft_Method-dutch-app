## DA-001 · Start the v2 branch

**Goal:** Preserve v1 safely and start a clean `v2` branch that holds only the new docs.

**Context:** `docs/architecture.md` (ADR-001), `docs/roadmap.md`

**Scope**
1. Make sure the working tree only has the new, uncommitted `docs/` folder and the `.gitignore` change. Stop and ask if there is anything else.
2. On `main`, tag the current `HEAD` (before any v2 changes) as `v1-legacy` and push the tag: `git tag v1-legacy && git push origin v1-legacy`.
3. Create and switch to the branch `v2` from `main`.
4. Move `docs/_v2-root/README.md` to `README.md` (replacing the old one) and `docs/_v2-root/CLAUDE.md` to `CLAUDE.md` (replacing the old one). Delete the empty `docs/_v2-root/` folder.
5. Stop tracking the agent files: `git rm --cached CLAUDE.md AGENTS.md`. Both stay on disk; `.gitignore` already lists them.
6. Remove all v1 source and config: `src/`, `public/`, `next.config.ts`, `next-env.d.ts`, `package.json`, `package-lock.json`, `tsconfig.json`, `eslint.config.mjs`, `postcss.config.mjs`, and `.next/` and `node_modules/` locally.
7. Keep: `.gitignore`, `README.md`, `docs/`, and the local-only `CLAUDE.md`, `AGENTS.md` and `.env`.
8. Commit `chore: start v2 branch with docs only` and push `v2`.

**Out of scope**
- Scaffolding the new app (that's DA-002)
- Touching `main` beyond the tag. Vercel production keeps serving v1 from `main` until launch.
- Deleting the MongoDB database

**Acceptance criteria**
- [ ] Tag `v1-legacy` exists on the remote and points at the last v1 commit
- [ ] Branch `v2` exists on the remote
- [ ] `git ls-files` on `v2` lists only `.gitignore`, `README.md` and `docs/**`
- [ ] `CLAUDE.md` and `AGENTS.md` exist locally but are not tracked (`git check-ignore CLAUDE.md` prints the path)
- [ ] `main` is unchanged apart from the tag

**Notes**
- This is the one ticket without a PR: it's branch setup. Report what you ran instead.
- `.env` holds v1's MongoDB URI and admin password. Leave it untracked. We'll delete it once v2 no longer needs v1's data.
